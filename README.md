# It's Raining Burgers 🍔

Site institucional de uma hamburgueria artesanal desenvolvido como projeto acadêmico da disciplina **Experiência Criativa** (TDE 3).

## Sobre o Projeto

Este projeto foi desenvolvido como exercício prático de construção de sites utilizando **somente HTML e CSS**, sem nenhum framework ou JavaScript. O trabalho envolveu desde a coleta de requisitos com um cliente fictício até a entrega do produto final.

A proposta foi simular um processo real de desenvolvimento web: realizamos uma entrevista com o cliente para entender suas necessidades, levantamos os requisitos funcionais e estruturamos o site com base nessas informações.

## Estrutura do Site

| Seção | Descrição |
|---|---|
| **Início / Hero** | Apresentação da hamburgueria com chamada para ação |
| **Diferenciais** | Blend próprio, pão artesanal e ingredientes frescos |
| **Promoções** | Ofertas da semana com preços e descontos em destaque |
| **Cardápio** | Lista de produtos com fotos e preços, com filtro por categoria (CSS puro) |
| **Números** | Estatísticas da hamburgueria (clientes, avaliação, ano de fundação) |
| **Sobre Nós** | História da hamburgueria |
| **Contato** | Formulário de contato, endereço, telefone, horários e mapa |
| **Login** | Tela de acesso para cliente e administrador |
| **Painel Admin** | Gerenciamento de cardápio (visualização e cadastro de produtos) |

## Tecnologias

- HTML5
- CSS3 (Flexbox, Grid, variáveis CSS, pseudo-seletores `:target` e `:has`)
- Google Fonts (Oswald + Inter)

> Nenhum JavaScript foi utilizado. Funcionalidades como filtro de cardápio por categoria, troca entre as views (site / login / admin) e as abas do painel administrativo foram implementadas com CSS puro, usando `<input type="radio">` e os seletores `:checked` e `:target`.

## Requisitos Levantados na Entrevista

Com base na entrevista com o cliente, os seguintes requisitos foram definidos:

**Funcionais:**
- Página inicial com apresentação e promoções em destaque
- Cardápio completo com categorias, fotos e preços
- Formulário de contato
- Exibição de endereço, telefone e horário de funcionamento
- Tela de login para cliente e administrador
- Painel administrativo para gerenciar o cardápio

**Não-funcionais:**
- Site responsivo (mobile-first)
- Navegação clara e intuitiva
